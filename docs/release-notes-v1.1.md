## 永劫无间 · 免下载切客户端 v1.1

用你已经下载过的客户端文件，重建另一个渠道的客户端 —— **90 GB 的游戏，真正需要下载的只有几百 MB**。

### 本版内容

- 单文件 C# WinForms 工具，**无任何外部依赖**，不需要安装 Python / Node / .NET SDK
- **A 模式**：读取目标渠道的官方文件清单，逐文件 MD5 校验后用**硬链接**复用本机已有文件，
  只从官方 CDN 下载真正缺失/不一致的部分
- **B 模式**：整树播种，把已有客户端链接/复制过去，再交给 Epic / Steam 自带的
  "验证游戏文件完整性"补差
- **硬链接 / 复制**两种复用方式；跨磁盘、源=目标、扫描后改路径等误操作会被明确拦下
- **三步流程**：① 扫描（干跑，只读不写）→ ② 执行 → ③ 验收，全程实时进度与百分比
- 每次运行生成报告（`plan.csv` / `download.csv` / `failures.txt`）与**一键回滚脚本**
  （`rollback.cmd` 双击即用，另有 UTF-8 的 `rollback.ps1`）
- 首次运行**强制阅读免责声明**，同意记录写入 `settings.ini`，之后可在界面内随时复查

### 使用前提

- 本机已经装过**任意一个渠道**能正常游玩的《永劫无间》（这是"免下载"的前提）
- 硬链接要求源目录与目标目录在**同一个磁盘分区**；不在同一分区请改用"复制"
